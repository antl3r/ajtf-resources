# Transmitting Coordinates

Coordinates should be spoken slowly and clearly.

Never rush numbers.

---

## Good

```
Grid.

One Two Three Four.

Five Six Seven Eight.
```

---

## Better

If talking to another station:

```
Alpha, this is Bravo.

Grid follows.

One Two Three Four.

Five Six Seven Eight.
```

---

## Confirming

The receiving station should repeat the coordinate.

```
Copy.

One Two Three Four.

Five Six Seven Eight.
```

This catches mistakes before people begin moving.

---

## Repeat Digits Individually

Say:

```
One

Zero

Seven

Nine
```

Not:

```
Ten

Seventy-nine
```

Every digit should be unmistakable.

---

## Speak Clearly

If you make a mistake:

Stop.

Start the coordinate again.

Do not try to correct yourself halfway through.
