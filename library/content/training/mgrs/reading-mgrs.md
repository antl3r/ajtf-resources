# Reading an MGRS Coordinate

Always read:

**Easting first.**

Then:

**Northing.**

Remember:

> **Right, then Up.**

---

## Example

```
1234 5678
```

Read:

```
One Two Three Four

Five Six Seven Eight
```

Do not combine them into one long number.

Incorrect:

```
Twelve thousand...
```

Correct:

```
One Two Three Four...

Five Six Seven Eight.
```

This greatly reduces mistakes over the radio.

---

## Group the Numbers

Pause between Easting and Northing.

```
1234

5678
```

This makes coordinates easier to hear.
