# Common Mistakes

## Reading Northing First

<font color="red">Wrong</font>

```
5678 1234
```

<font color="green">Correct</font>

```
1234 5678
```

Always:

Right, then Up.

---

## Speaking Too Fast

<font color="red">Wrong</font>

```
One-two-three-four-five-six-seven-eight
```

<font color="green">Correct</font>

```
One Two Three Four.

Five Six Seven Eight.
```

---

## Forgetting Accuracy

A 4-digit coordinate describes a much larger area than an 8-digit coordinate.

If directing a squad onto a building:

Use an 8-digit coordinate whenever possible.

---

## Guessing

If you're unsure of a digit:

Check the map again.

A wrong coordinate can place an entire squad hundreds of meters away.
