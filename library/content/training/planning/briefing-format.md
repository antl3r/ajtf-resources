# Standard Squad Brief

Most briefings can be completed in under two minutes.

Follow this order.

---

## 1. Situation

What do we know?

```
Enemy platoon occupying the village.

Minimal anti-air capability.
```

---

## 2. Infiltration

```
Helicopter insertion.

Landing at LZ Falcon.
```

---

## 3. Objective

```
Clear the village.

Capture enemy documents.
```

---

## 4. Exfiltration

```
Move to PZ Eagle.

Helicopter extraction.
```

---

## 5. Contingencies

```
If separated:

Rally at Checkpoint Bravo.

If extraction unavailable:

Move south to alternate PZ.
```

---

## 6. Questions

Resolve confusion now.

Not after landing.
