# Airhead Security

The first players off the helicopter have one job:

Protect everyone else.

---

# Cover, Don't Crowd

After leaving the aircraft:

Move away from it.

Find nearby cover if available.

Avoid forming a circle around the helicopter.

---

# Watch Different Directions

Don't let everyone stare at the same area.

Spread your observation.

A good airhead provides security in every likely direction.

---

# Report Threats

If you identify enemies:

Report them immediately.

Example:

```
Enemy squad east.

Holding.
```

---

# Don't Chase

The purpose of the airhead is security.

It is **not** to pursue distant enemies.

Maintain security until the unit is ready to move.
