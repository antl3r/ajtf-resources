# Passenger Coordination

Good passengers make good pilots.

---

# Listen to the Crew

The pilot and crew chief control the aircraft.

If they give an instruction:

Follow it immediately.

---

# Keep Radio Traffic Short

Avoid unnecessary radio traffic during:

- landing
- takeoff
- final approach

Pilots already have enough to manage.

Transmit only important information.

---

# Announce Problems

If something affects the mission:

Report it.

Examples:

```
One passenger left behind.
```

```
Aircraft taking fire north.
```

```
LZ occupied.
```

---

# Once You're Off

The helicopter's mission is finished.

Don't continue using local voice to communicate with the aircraft unless necessary.

Allow the crew to focus on departure.
