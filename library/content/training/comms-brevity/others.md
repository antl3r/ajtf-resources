# Other Brevity Codes

| Brevity           | Meaning                                            |
| ----------------- | -------------------------------------------------- |
| Affirm            | Yes                                                |
| Negative          | No                                                 |
| Copy              | Message received                                   |
| Roger             | Message received (legacy)                          |
| Wilco             | Understood, will comply                            |
| Say Again         | Repeat your last transmission                      |
| Break             | Separate unrelated information                     |
| Stand By          | Wait for further information                       |
| Wait, Out         | Pause; conversation will resume later              |
| Out               | Conversation finished                              |
| Radio Check       | Check radio readability                            |
| Loud and Clear    | Excellent signal                                   |
| Weak but Readable | Understandable with poor reception                 |
| Contact           | Enemy sighted                                      |
| TIC               | Troops in contact                                  |
| Winchester        | Out of ammunition                                  |
| Bingo             | Minimum fuel to return safely                      |
| Joker             | Planned fuel state before Bingo                    |
| RTB               | Return to Base                                     |
| Oscar Mike        | On the move                                        |
| Rally             | Move to the rally point                            |
| LZ                | Landing Zone                                       |
| HLZ               | Helicopter Landing Zone                            |
| Hot LZ            | Landing zone under enemy threat                    |
| Cold LZ           | Landing zone appears safe                          |
| Wave Off          | Abort landing/approach                             |
| Abort             | Stop the current action immediately                |
| Splash            | Target destroyed                                   |
| Visual            | I have visual contact                              |
| Blind             | I have lost visual contact                         |
| Tally             | Visual contact with the enemy                      |
| No Joy            | Enemy not in sight                                 |
| Stand Fast        | Hold current position                              |
| Push              | Switch to or begin using a designated frequency    |
| Check Fire        | Stop firing immediately                            |
| Cease Fire        | Stop firing; engage only if necessary              |

| Weapons Tight     | Fire only at positively identified hostile targets |
| Weapons Hold      | Do not fire unless specifically ordered            |
