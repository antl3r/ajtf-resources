# Radio Discipline

Everyone shares the same channel.

One unnecessary transmission prevents someone else from speaking.

## Think Before You Transmit

Ask yourself:

> Does somebody else actually need this information?

If not, don't transmit it.

---

## Keep It Short

Good:

```
Enemy squad west.

Moving north.
```

Bad:

```
Uh... I think maybe...
They're sort of over by...
```

---

## Don't Interrupt

If someone is already transmitting:

Wait.

Then speak.

Talking over each other helps nobody.

---

## Stay Calm

Your voice influences everyone listening.

Even under pressure:

```
Taking fire north.

Need support.
```

is far more useful than

```
OH MY GOD WE'RE ALL DEAD
```

---

## Repeat Important Information

Critical messages can be repeated once if necessary.

```
Medic needed.

Repeat, medic needed.
```

Don't repeat routine messages.
