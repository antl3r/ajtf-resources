# Making Reports

A useful report answers a few simple questions.

1. What happened?
2. Where?
3. What do you need?

You don't always need every piece.

---

## Enemy Report

```
Alpha, this is Bravo.

Enemy fireteam crossing the road east of us.
```

---

## Contact Report

```
Taking fire from the apartment building.

Returning fire.
```

---

## Casualty Report

```
One man down.

Need a medic.
```

---

## Status Report

```
Objective secure.

Holding position.
```

---

## Request

```
Need smoke on the south entrance.
```

```
Need helicopter extraction.
```

```
Need ammunition.
```

---

## Don't Narrate Everything

Don't constantly describe every movement.

Bad:

```
I'm walking around the building...
I'm looking left...
I'm moving upstairs...
```

Only transmit information that helps someone else make a decision.
