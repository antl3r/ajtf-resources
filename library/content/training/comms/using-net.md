# Using the Right Net

Not everyone needs to hear everything.

Use the radio that reaches the people who need your message.

## Squad Net

Use for:

- enemy contacts
- movement
- casualties
- orders
- logistics

## Fireteam Voice

Whenever possible, talk directly.

Instead of:

```
I'm moving left.
```

Just tell your buddy.

Save the radio for information everyone needs.

## Command Net

Only leaders should normally use this net.

Typical traffic:

- objective complete
- requesting support
- requesting extraction
- reports to higher command

Keep command channels quiet.
