## Poor Example

```
Guys guys guys!

They're everywhere!

Help!
```

Problems:

- no recipient
- no location
- no useful information

---

## Better Version

```
Alpha, this is Bravo.

Enemy squad west of warehouse.

Need support.
```

Now everyone knows:

- who reported it
- where the enemy is
- what is needed
