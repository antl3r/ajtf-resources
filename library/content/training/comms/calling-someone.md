# Calling Someone

Every transmission has the same basic structure.

```
[WHO YOU ARE CALLING], THIS IS [YOU]
```

Examples:

```
Alpha, this is Bravo.
```

```
Actual, this is One-One.
```

Wait for them to answer.

```
Go ahead.
```

Then send your message.

---

## Good

```
Alpha, this is Bravo.

Go ahead.

Enemy squad crossing road north of church.
```

Everyone immediately knows:

- who is speaking
- who should listen
- what happened

---

## Bad

```
Enemy!
Enemy!
They're over there!
```

Nobody knows:

- who is talking
- where
- who should respond

---

## Keep It Natural

Don't try to memorize dozens of radio words.

Speak normally.

Bad:

```
Be advised that hostile elements appear to be...
```

Better:

```
Enemy squad north of the church.
```

Short and clear always wins.
